# 屏幕壁纸

- 顶栏「更换壁纸」打开设置，可分别选择外屏与内屏图片，并单独恢复默认。
- 支持 JPG、PNG、WebP，每张最多 20 MB。按屏幕实际比例居中等比裁剪铺满，不拉伸；长边最多 1536 像素，透明区域以黑色填充。
- 处理后的图片仅保存在当前浏览器的本地存储中，不上传服务器。刷新后恢复；不同浏览器、不同网站地址之间不共享，清除站点数据会删除壁纸。
- 壁纸跨机身配色保持。开合和电源仍控制哪块屏幕亮起，恢复默认使用各模型原有贴图。
- 模型默认贴图已更新为用户提供的高清 PNG：星白外屏 `ComfyUI_00036_.png`、内屏 `ComfyUI_00037_.png`；夜空外屏 `ComfyUI_00034_.png`、内屏 `ComfyUI_00035_.png`。外屏 2896×5792，内屏 5792×2896，原始文件字节直接嵌入，不经过上传功能的尺寸限制或缩放。
- 图片读取失败时保留旧壁纸。保存失败时新壁纸仍在当前页面显示，同时明确提示刷新可能还原。

屏幕图片替换发光贴图，保留玻璃材质；自定义纹理由查看器统一拥有，在替换及退出时释放，避免跨配色重复释放。文件设置对每块屏幕串行处理，初始化读取完成前禁用更换，以避免旧保存覆盖新选择。

高清默认图同时导出在 `public/wallpapers/`。原模型备份位于 `docs/model-backups/before-hd-wallpapers/`，模型清单记录新版文件大小和 SHA-256。可用 `node scripts/replace-default-wallpapers.mjs <图片目录>` 重新打包；脚本校验所有非壁纸 buffer view 的字节及其他模型描述保持一致。模型请求带版本参数以更新浏览器缓存；用户已保存的自定义壁纸仍优先显示。

验证：15 项自动测试及生产构建通过。浏览器使用 `docs/qa/wallpaper-grid.png` 检查内外屏文字方向、圆形比例、刷新恢复、夜空色切换、电源关闭与重新打开、两屏独立恢复默认和 375px 窄屏面板。测试后已恢复默认壁纸，并再次刷新确认。
