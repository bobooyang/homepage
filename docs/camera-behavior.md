# 相机预览

- 点击机身相机按钮，自动亮屏并请求使用设备默认摄像头；仅请求视频，不请求麦克风。
- 授权成功后，实时画面在手机当前亮屏内居中等比裁剪铺满，保留屏幕玻璃效果。开合切换内外屏，机身配色切换时预览继续。
- 再按相机按钮关闭预览、释放摄像头并恢复原壁纸。授权等待期间再次点击也会取消此次启动；迟到的授权结果立即释放。
- 按电源关屏、离开页面或销毁查看器时停止摄像头。重新亮屏不会自动启动预览。
- 权限拒绝、设备缺失、占用、播放失败或设备断开时恢复壁纸并给出提示，可再次点击重试。摄像头需要支持媒体采集的浏览器及 HTTPS 或 localhost 环境。
- 预览期间修改壁纸会保留新设置，关闭预览后显示；预览不拍照、不录像、不上传，不持久化摄像头状态。

验证：23 项自动测试及生产构建通过。新增测试覆盖启动/释放、迟到授权、取消后重新启动、销毁期间授权返回、权限失败重试、设备断开及播放失败。浏览器验证了机身相机点击、设备缺失提示、关屏及相机自动亮屏；测试浏览器没有可用摄像头，真实视频在模型屏幕上的视觉效果尚未实机验证。
