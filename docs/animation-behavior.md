# 视角与开合动画

已确认的交互规则：

- 正面、背面、左侧、右侧、立体之间绕模型连续转动，柔和起步、减速停稳，主要运动约 0.6–0.8 秒。
- 合上与展开采用相同节奏。角度滑块立即反映目标角度，机身约 0.1 秒平滑追随；角度读数反映实际姿态。
- 连续操作立即更新目标，保留当前姿态和运动速度，不排队播放旧操作。
- 视角与开合可以同时运动。手动旋转、缩放或平移立即接管镜头，不中止开合。
- 尊重系统“减少动态效果”偏好，直接到达目标。

视角选择器的白色胶囊为视角选中指示器。选项改变时，指示器在约 250ms 内平滑减速滑向新选项，文字保持原位；连续点击从当前位置转向最新选项，不排队。首次显示直接定位，系统开启“减少动态效果”时取消滑动。手动接管导致没有预设视角选中时，隐藏指示器。此效果仅适用于五个预设视角选项。

实现采用临界阻尼运动；镜头在球坐标中沿较短方位角方向转动，避免正背面切换时穿过模型。开合范围限定为 0–180°，屏幕切换仍依据实际角度的 20°/30° 阈值。

验证包含所有预设视角组合、中途反向、连续目标变更、滑块任意角度、帧率一致性与机身交互状态保持。
