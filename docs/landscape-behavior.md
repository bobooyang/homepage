# 手机横屏适配

## 已确认的布局

- 使用紧凑顶栏和单行底栏，模型居中展示。
- 隐藏操作说明及「交互模型 / 3D 体验」小字。
- 保留标题、设备状态和全部操作入口。

## 切屏行为

- 尺寸变化时保留观察方向，自动调整距离并居中，手动操作后也重新完整取景。
- 保留配色、开合、屏幕、音量、壁纸和相机状态，不重播入场动画。
- 横屏且视口高度不超过 600px 时启用紧凑布局，画布位于顶底栏之间。
- 使用动态视口高度，边缘避开刘海和系统手势安全区。
- 壁纸弹窗在短屏内可滚动。

## 验证

- 浏览器验证 956×440、568×320、667×375 横屏，模型与操作栏完整显示。
- 手动旋转后切至 390×844 竖屏再返回横屏，开合及屏幕状态保留，入场不重播。
- 横屏壁纸弹窗可打开、关闭，浏览器未报告错误。
- TypeScript 检查、23 项现有测试及生产构建通过。
- 刘海安全区已使用 CSS 环境变量适配，尚未在真实手机浏览器验证。
