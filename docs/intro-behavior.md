# 入场展示

每次打开或刷新页面播放一次；切换机身配色、壁纸与视角不重播。

1. 准备：顶底栏和画布初始隐藏，模型及本地壁纸恢复完成后开始。模型加载失败时保留中央重试入口。
2. 旋转渐显（1.45 秒）：手机保持闭合，从背侧斜角旋转 240°，逐渐转为正面；前 0.8 秒完成渐显。
3. 展开（0.75 秒）：转正后立即开始，保持正面，平滑展开到 180°。旋转和展开使用三次平滑缓动，缩短接近静止的收尾与起步，同时保持端点速度连续。
4. 栏位入场（0.55 秒）：顶栏从上方、底栏从下方滑入并渐显，随后恢复交互。

总计约 2.75 秒，不包含资源加载时间。播放时提供「跳过动画」，直接进入正面、完全展开、顶底栏可操作的终态。系统启用“减少动态效果”时直接跳至终态。

初始隐藏同时处理可见性、辅助技术与键盘焦点；壁纸设置组件保持挂载以完成本地恢复。入场使用独立的定向旋转时间线，结束后再交还现有视角与开合控制。窗口缩放只重算取景，不重启时间线。

验证要求：旋转结束立即进入展开，100 毫秒内展开超过 5°，旋转末尾不出现长时间近似静止；各阶段位置连续、角度单调变化，完全展开后才显示栏位。跳过后立即为正面 180° 且栏位可交互，配色切换不重播，入场后的开合与视角控制正常。
